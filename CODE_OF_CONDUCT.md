# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep it about the code. Harassment, insults and personal attacks aren't welcome in issues, pull requests or anywhere else in the project.

Report problems to p.podolak@gmail.com. Reports are handled privately.
